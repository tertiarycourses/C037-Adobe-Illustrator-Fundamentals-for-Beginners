# Tools & Setup — Generative AI for Concept Art (C037)

Everything you need for the 9 hands-on labs. This course uses **generative-AI
image tools** to make concept art and an **image editor** to finish it. You do
not need all three generators — pick the one you have access to; the trainer will
confirm which the class uses.

## Accounts & software

| Tool | What it's for | Notes |
|---|---|---|
| **An AI image generator** (choose one) | Generating characters, environments, props and key art | See the three options below — a paid plan or trial with generations/credits available |
| **Midjourney** | A strong, painterly, art-directed look | Runs in Discord or the web app; uses `/imagine` and parameters such as `--ar`, `--stylize`, `--seed`, `--sref` |
| **Stable Diffusion** (via a hosted UI) | Open, highly controllable generation | Leonardo.Ai or DreamStudio in the browser (or a local install); supports seeds, models, LoRAs, ControlNet, inpainting |
| **Adobe Firefly** | Commercial-safe generation & in-editor editing | Web app, or built into Photoshop as **Generative Fill** |
| **An image editor with layers** | Assembling sheets, inpainting, paint-over, export | **Photoshop** (with Generative Fill) is ideal; the free **Krita** or browser-based **Photopea** also work |
| **Internet connection** | The generators run in the cloud | Required for every generative step |

## Before Lab 1 — confirm your setup

1. **Sign in** to your chosen AI image generator (Midjourney / a Stable Diffusion tool / Adobe Firefly) and confirm you have generations or credits available.
2. Run **one test generation** to confirm it works.
3. Open your **image editor** (Photoshop / Krita / Photopea) and create a new layered document.
4. Create a project folder called **`Emberdrift`** for all your images.

If any of these is missing, tell the trainer at the start of the day.

## The connected project

Every lab builds one piece of the **Emberdrift** concept-art pack (see
[reference-pack/](reference-pack/)). Keep every image in your `Emberdrift` folder
so the pack stays together. There is **no assessment** — each lab verifies itself
with a **Test it** step.
