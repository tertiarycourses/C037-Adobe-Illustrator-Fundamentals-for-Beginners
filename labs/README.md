# Adobe Illustrator Fundamentals for Beginners — Labs

**Course code:** C037
**Version:** v1 · 4 October 2026

Each lab is self-contained. Open its folder, read the guide, and work only on the supplied Illustrator/vector assets. Save all outputs inside the same lab folder or your trainer-approved workspace.

## Lab sequence

1. [Lab 01 — Workspace, Artboards and Selection](lab-01-workspace-selection/README.md) — Set up a reliable vector workspace and distinguish object, group and anchor-level selection.
2. [Lab 02 — Shapes, Lines and Transform Systems](lab-02-shapes-transform/README.md) — Construct a precise icon set from live shapes and numeric transforms.
3. [Lab 03 — Colour Systems, Swatches and Strokes](lab-03-colour-strokes/README.md) — Create screen and print colour variants with a controlled stroke language.
4. [Lab 04 — Layers, Groups and Alignment](lab-04-layers-groups-alignment/README.md) — Reorganise a complex document so stacking, grouping and alignment are clear and auditable.
5. [Lab 05 — Pathfinder, Shape Builder and Masks](lab-05-construction-masks/README.md) — Compare construction methods and select the most editable result for a badge system.
6. [Lab 06 — Pen, Curvature, Pencil and Brushes](lab-06-pen-pencil-brush/README.md) — Create controlled and expressive paths while keeping anchor economy and brush behaviour visible.
7. [Lab 07 — Gradients, Patterns and Symbols](lab-07-gradients-patterns-symbols/README.md) — Build reusable colour and repetition systems, then improve one option through controlled experimentation.
8. [Lab 08 — Appearance, Graphic Styles and Typography](lab-08-appearance-typography/README.md) — Design a typographic poster with live type and reusable appearance treatments.
9. [Lab 09 — Image Trace, Artboards and Export](lab-09-image-trace-artboards-export/README.md) — Convert suitable raster artwork, clean the vector result and deliver a verified multi-artboard asset set.
10. [Lab 10 — Brand System Capstone, Handoff and Peer Review](lab-10-brand-system-capstone/README.md) — Integrate the course workflow into a coherent vector brand kit, evaluate it and prepare a rights-aware handoff.
