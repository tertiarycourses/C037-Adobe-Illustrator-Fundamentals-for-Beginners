## Lab Activities

The 9 labs form one connected practical journey. Complete them in order so each verified output can support the activities that follow.

| # | Activity | Outcome |
|---:|----------|---------|
| **1** | [Get Started with Generative AI Image Tools](labs/lab-01-get-started-with-generative-ai-image-tools.md) | Sign in to your AI image generator, run your first generations, compare Midjourney, Stable Diffusion and Firefly, and learn the generate–review–refine loop that every later lab uses. |
| **2** | [Write Effective Prompts for Concept Art](labs/lab-02-write-effective-prompts-for-concept-art.md) | Turn the supplied Emberdrift brief into a strong, structured prompt that controls subject, style, composition, shot, lighting and detail, and save it as a reusable template. |
| **3** | [Generate Character Concepts](labs/lab-03-generate-character-concepts.md) | Use your prompt to generate the Emberdrift hero character (Wren) with a consistent design, then explore costume, pose and expression variations and curate the strongest. |
| **4** | [Generate Environment Concepts](labs/lab-04-generate-environment-concepts.md) | Generate the Emberdrift key environment — a floating lantern sky-port at dusk — controlling place, time of day, mood, scale and shot, and curate the strongest establishing image. |
| **5** | [Generate a Prop and Asset Sheet](labs/lab-05-generate-a-prop-and-asset-sheet.md) | Generate Wren's salvaging gear as individual props on clean backgrounds and assemble them into a coherent asset sheet that matches the pack's style. |
| **6** | [Develop a Consistent Style and Strong Compositions](labs/lab-06-develop-a-consistent-style-and-strong-compositions.md) | Lock a repeatable house style for Emberdrift and thumbnail strong compositions, so the character, environment and props all read as one world. |
| **7** | [Iterate and Refine Artwork](labs/lab-07-iterate-and-refine-artwork.md) | Take one chosen piece and refine it with variations, reused seeds, image-to-image and style/character references until it matches your intent and stays consistent. |
| **8** | [Edit and Enhance with Inpainting, Outpainting and Paint-Over](labs/lab-08-edit-and-enhance-with-inpainting-outpainting-and-paint-over.md) | Finish your key-art piece by fixing regions with inpainting, widening the frame with outpainting, upscaling for resolution, and adding a hand paint-over in your image editor. |
| **9** | [Build and Present the Concept-Art Portfolio](labs/lab-09-build-and-present-the-concept-art-portfolio.md) | Curate the Emberdrift pieces into a presented concept-art portfolio, assemble and export it, and apply commercial-use and IP considerations before delivery. |

## About

This repository contains the complete lab and courseware package for **Generative AI for Concept Art** (**C037**) by Tertiary Courses / Tertiary Infotech. The practical activities build progressively from **Get Started with Generative AI Image Tools** to **Build and Present the Concept-Art Portfolio**, with explicit checks that help learners verify each result before moving on.

### What you'll learn

- Complete **9 connected hands-on activities** and carry their outputs through one coherent learning journey.
- Practise with **Adobe Photoshop · Adobe Firefly · Midjourney · Stable Diffusion** and the supporting resources supplied in the repository.
- Begin with **Get Started with Generative AI Image Tools** and finish with **Build and Present the Concept-Art Portfolio**.
- Apply safe data handling, evidence checks and named human review before using AI-generated or automated outputs.

## Getting Started

### Prerequisites

- The accounts and software required for **Adobe Photoshop · Adobe Firefly · Midjourney · Stable Diffusion**. Follow the setup and access notes in each lab.
- Review [`labs/tools.md`](labs/tools.md) before class for environment, account and safe-use requirements.
- A modern web browser and Git for cloning the materials.
- Synthetic or authorised data only. Do not place secrets, personal data or confidential material into an unapproved service.
- A named human reviewer for facts, calculations, decisions and any externally released output.

### 1. Clone the repository

```bash
git clone https://github.com/tertiarycourses/C037---Generative-AI-for-Concept-Art.git
cd C037---Generative-AI-for-Concept-Art
```

### 2. Open the lab index

Start with [labs/README.md](labs/README.md), then complete Labs 1–9 in order. Each lab provides the activity context, practical steps and a way to verify the result.

### 3. Keep your connected outputs

Store each lab output in the suggested working folder and retain the evidence or review notes requested by the lab. Later activities depend on these approved outputs.
